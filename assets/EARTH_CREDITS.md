# Earth model

`earth.glb` was supplied by the project owner. Its embedded metadata attributes **Earth** to **Akshat** and identifies the source as https://sketchfab.com/3d-models/earth-41fc80d85dfd480281f21b74b2de2faa under **CC BY 4.0**: https://creativecommons.org/licenses/by/4.0/.

Moonbound uses the model and its embedded texture in the flight and orbital-map views. The source GLB is unchanged; the game scales and positions instances at runtime.
