# Moonbound

Moonbound is a Godot game about designing and flying a crewed Moon mission. Plan the Lunar Dawn expedition, choose a landing region, crew, orbit, and spacecraft parts, then balance funding, mass, power, communications, and flight performance. Manufacture and test the vehicle before launching, navigating to the Moon, and landing.

The current playable chapter ends at lunar touchdown. Surface operations and the return trip are planned future chapters. Physics and engineering values are scaled for gameplay and are not NASA mission requirements.

## Run

Open `project.godot` in Godot 4.7 and run the project. The main scene is `scenes/main.tscn`. Progress saves automatically; the campaign can also be saved with Ctrl/Cmd+S.

## How to play

1. Choose a landing region, orbit, and two crew members.
2. Select spacecraft modules and check the live mission budgets.
3. Manufacture, integrate, and complete the qualification tests.
4. Authorize launch, enter the flight deck, reach Earth orbit, transfer to the Moon, and land.

The game includes an in-game guide. In flight, use **Space** to launch or stage, **A/D** or **W/S** to turn, **Shift/Ctrl** to change throttle, **M** for the orbital map, and **P/R** for prograde or retrograde guidance. Use **F5/F9** to save or load a flight checkpoint.
