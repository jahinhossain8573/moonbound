# Bundled fonts

These unmodified fonts are bundled so the game's typography is consistent across machines. Each is licensed under the SIL Open Font License, Version 1.1; the corresponding `OFL-*.txt` file is included here.

| Font | In-game use | Source |
| --- | --- | --- |
| Audiowide Regular | Buttons, headings, names | [Google Fonts / Audiowide](https://github.com/google/fonts/tree/main/ofl/audiowide) |
| Unbounded variable | Main interface text | [Google Fonts / Unbounded](https://github.com/google/fonts/tree/main/ofl/unbounded) |
| Electrolize Regular | Moonbound wordmark | [Google Fonts / Electrolize](https://github.com/google/fonts/tree/main/ofl/electrolize) |

The [Figma futuristic font guide](https://www.figma.com/resource-library/futuristic-fonts/) provided the typography direction.
